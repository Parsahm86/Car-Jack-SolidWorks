# Car Jack Assembly - SolidWorks Design

This repository contains the complete mechanical design of a Scissor Car Jack, designed and drafted in SolidWorks 2025.

## Project Overview
This project is a fully functional, manufacturable car jack assembly. It includes:
*   **10 Unique Parts:** From sheet metal bases and arms to precision machined pins and screw rods.
*   **Manufacturing Compliance:** All parts are drafted according to **ISO 2768-mK** (Medium) and **ISO 2768-cK** (Coarse) tolerances.
*   **GD&T (Geometric Dimensioning and Tolerancing):** Used to ensure correct assembly and fit (e.g., Cylindricity, Perpendicularity, Position tolerances).
*   **Standards:** Applied ISO and DIN standards for threads (Metric, Trapezoidal) and fits (h9, H11).

## Files Included
*   `/SolidWorks_Files/`: Contains all original `.sldprt`, `.sldasm`, and `.slddrw` files.
*   `Drawing_Files.pdf`: A complete 12-page PDF containing 2D manufacturing drawings, Bill of Materials (BOM), and an Exploded View.
*   `Cover_Image.png`: A high-quality render of the final assembly.

## Technical Features
*   **Material Selection:**
    *   Sheet metal parts: St37-2 (S235JR) / AISI 1023.
    *   Machined parts (Pins, Screws, Nuts): AISI 1045 / AISI 4140.
*   **Threads:** Standard Metric (M), DIN standard, and Trapezoidal (Tr) threads for the power screw.
*   **Tolerances:** Applied MMC (Maximum Material Condition) for mating holes to reduce manufacturing costs.

## How to Use
1.  Clone or download the repository.
2.  Open `.sldasm` file in **SolidWorks 2025** (or newer).
3.  For manufacturing, refer to the `Drawing_Files.pdf`.
